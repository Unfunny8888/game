# Их Монгол V2 — инженерийн эхлэлийн төлөвлөгөө

> Зорилго: **Mobile Legends маягийн стилизацдсан 3D**, co-op survival-RPG.
> Энэ баримт нь Unity хөгжүүлэгч эхлэхэд шаардлагатай бүх зүйлийг тодорхойлно.

## 1. Технологийн стек
| Давхарга | Сонголт | Тэмдэглэл |
|---|---|---|
| Хөдөлгүүр | **Unity 2022.3 LTS+** (URP) | Гар утсанд оптимизацитай, стилизацдсан 3D |
| Рендер | Universal Render Pipeline | Toon/stylized shader, тод өнгө |
| Камер | Isometric follow (≈45°/30°) | MLBB шиг дээрээс харсан өнцөг |
| Оролт | Тап-хийж-хөдлөх + чадварын товч | `HeroController.cs` |
| Netcode | **Netcode for GameObjects** (эрх мэдэлт хост) | `Net/ICoopSession` интерфейсээр солигдоно (Mirror/Photon) |
| Backend | PlayFab / Firebase (данс, хадгалалт) | Дараагийн үе |
| Платформ | iOS + Android | Нэг код |

## 2. Төслийн бүтэц (Unity дотор)
```

│   ├── Meta/         дүр тохируулах, ахиц
│   ├── World/        эзлэлт, түвшин, quest
```

## 3. Босоо зүсэлт (Vertical slice) — эхний милестон
Зорилго: **нэг хот, co-op, зугаатай юу?**-г батлах.
1. Газар (plane) + `IsoCameraRig` + баатар prefab.
2. `HeroController` — тап хийж хөдлөх, ойрын дайсныг автоматаар цохих, 1 чадвар.
3. `Health` — амь, хохирол, үхэл; энгийн дайсны AI (ойртож цохих).
4. 2–4 тоглогчийн co-op (`ICoopSession` → эхлээд `LocalCoopSession`, дараа нь NGO хост).
5. `ConquestManager` — Отрар хотыг эзлэх: хэрэм эвдэх → хамгаалагч → тугийн уналт.
6. Эзлэлтийн мөчлөг: Эзлэх → Буурьших → Цуглах → Мородох (дараагийн хот).

## 4. Урлагийн чиглэл (MLBB маягийн стил)
- **Low-poly + toon shading**, тод ханатай өнгө, зөөлөн outline.
- Монгол хэрэглэл: дээл, ламелляр хуяг, шовгор дуулга, морь, гэр, овоо, тэрэг.
- Дайсны хот: Хорезм/Персийн бөмбөгөр сүм, минарет, шавар хэрэм.
- Анимаци: гүйх, цохих, чадвар, унах — MLBB шиг богино, тод.
- Дүр ≈ 3–6k триангл; гар утсанд 60fps зорино.

## 8. Netcode-ийн зарчим (V1-ийн загварыг үргэлжлүүлнэ)
V1 аль хэдийн **эрх мэдэлт хост** (host-authoritative) загвартай: зочин оролтоо
илгээж, хост тооцоолж, snapshot цацна. V2 үүнийг Unity дээр давтана —
`ICoopSession` интерфейс нь энэ гэрээг тодорхойлж, доор нь NGO/Mirror/Photon-ыг
залгаж болно. Эхлээд `LocalCoopSession` (нэг төхөөрөмж) дээр логикоо турш.
