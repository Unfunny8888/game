# Их Монгол — Тулааны Талбар ⚔️

**Mobile Legends маягийн, монгол сэдэвт тулааны тоглоом.** Чингис хаан болон түүний жанждыг удирдан, Хорезмын их хаалгыг нурааж ялалт байгуул!

A Mongolian-themed, Mobile Legends-style lane-battle game featuring Chinggis Khaan and his generals. Fully in the Mongolian language. iPhone-first (iPhone X and newer).

## 📱 Native iOS хувилбар (гол хувилбар) — `ios/`

Swift + SpriteKit дээр бичигдсэн жинхэнэ native iPhone тоглоом.

- **Шаардлага:** Mac компьютер + [Xcode 15 буюу түүнээс дээш](https://apps.apple.com/app/xcode/id497799835) (үнэгүй), iPhone X-ээс дээш утас (iOS 15+)
- iPhone-д зориулсан, хөндлөн (landscape) байрлалтай
- Гар утасны мэдрэгч удирдлага: виртуал жойстик + чадварын товчнууд
- Хаптик (чичиргээт) мэдрэмж бүхий цохилтууд
- Дуу авиа: тал нутгийн аялгуут хөгжим + тулааны авианууд (🔊 товчоор унтраана)

### Хэрхэн ажиллуулах вэ

1. Энэ repo-г Mac дээрээ татаж авна:
   ```bash
   git clone <repo-url>
   ```
2. `ios/IkhMongol.xcodeproj` файлыг Xcode-оор нээнэ
3. Project Settings → **Signing & Capabilities** хэсэгт өөрийн Apple ID-гаа **Team** болгож сонгоно (үнэгүй Apple ID болно)
4. Утсаа кабелаар залгаад, дээд талын төхөөрөмжийн жагсаалтаас өөрийн iPhone-оо сонгоно
5. **▶ Run** товч дарна — тоглоом утсан дээр чинь суугдана
6. Утсан дээрээ анх удаа ажиллуулахдаа: **Тохиргоо → Ерөнхий → VPN ба төхөөрөмжийн удирдлага** хэсгээс өөрийн Apple ID-д итгэх (Trust), мөн iOS 16+ бол **Нууцлал ба аюулгүй байдал → Хөгжүүлэгчийн горим** (Developer Mode)-ыг асаана

> 💡 Үнэгүй Apple ID ашиглавал апп 7 хоног тутамд дахин суулгах шаардлагатай. App Store болон TestFlight-д байршуулахын тулд жилийн $99-ын Apple Developer Program хэрэгтэй.

## 🌐 Веб демо (шууд тоглох боломжтой) — `web/`

Native хувилбарыг угсрахад Mac хэрэгтэй тул **яг одоо iPhone дээрээ туршаад үзэх** веб хувилбарыг мөн хийсэн. Тоглоомын агуулга нь native хувилбартай ижил.

- iPhone-ийнхээ Safari дээр нээгээд л тоглоно (iPhone X ба түүнээс дээш бүх утсанд ажиллана)
- **Share → Add to Home Screen** хийвэл жинхэнэ апп шиг бүтэн дэлгэцээр ажиллана

### Хэрхэн нээх вэ

- **GitHub Pages** (санал болгож буй арга): Repo **Settings → Pages → Source: Deploy from a branch** → branch-аа сонгоод хадгална. 1-2 минутын дараа `https://<username>.github.io/<repo>/` хаягаар шууд тоглогдоно (үндсэн хуудас автоматаар тоглоом руу үсэрнэ)
- **Локал сервер:**
  ```bash
  cd web && python3 -m http.server 8080
  # утаснаасаа http://<компьютерийн-IP>:8080 хаягаар орно
  ```

## 🎮 Тоглоомын заавар

**Зорилго:** Дайсны **Их хаалга**-ыг нураах. Өөрийн хаалгаа алдвал ялагдана.

| Удирдлага | Үйлдэл |
|---|---|
| Дэлгэцийн зүүн тал | Виртуал жойстик — баатраа хөдөлгөнө |
| ⚔️ Том улаан товч | **Дарж байх зуур** довтолно — дайсны баатрыг эрхэмлэн онилж, хол бол ойртоно |
| Жижиг товчнууд (нуман) | Чадварууд (cooldown-тэй) |
| Энгийн довтолгоо | Зогсож байхад автоматаар цохино (хөдлөхөд зогсоно, ML маяг) |
| ✕ товч (баруун дээд) | Тулаанаас гарч үндсэн цэс рүү |
| Өөрийн хаалганы дэргэд | Амь аажмаар сэргэнэ |

### 🤝 Найзтайгаа тоглох (iOS, 1v1 PvP)

Үндсэн цэсний **НАЙЗТАЙГАА** товчоор орж, хоёр горимоос сонгоно:

- **📶 ОЙРОЛЦОО** — хоёр iPhone нэг Wi-Fi сүлжээнд эсвэл Bluetooth-ээр ойрхон байхад автоматаар холбогдоно. Ямар ч нэмэлт тохиргоо шаардлагагүй. Анхны удаад iOS "Local Network" зөвшөөрөл асуухад **Allow** дарна.
- **🌐 ОНЛАЙН** — Game Center-ээр интернэтийн хаанаас ч таарц хайна. Аль ч тохиолдолд хоёулаа баатраа сонгоод БЭЛЭН дарахад 1v1 тулаан эхэлнэ.

PvP-д бүх баатар нээлттэй, мастерийн нэмэгдэл үйлчлэхгүй (шударга тулаан). Ялбал 🪙100, ялагдвал 🪙30 алт.

#### Онлайн горимын тохиргоо (нэг удаа, developer account шаардлагатай)

1. **App Store Connect** → апп-аа сонгох → зүүн цэснээс **Game Center** (Services хэсэгт) → идэвхжүүлнэ
2. Xcode-д bundle ID тань App Store Connect дээрх апп-ын ID-тай **яг таарч** байгаа эсэхийг шалгана
3. Automatic signing асаалттай бол Xcode `IkhMongol.entitlements` файлын дагуу Game Center capability-г App ID дээрээ өөрөө бүртгэнэ
4. Туршилтын үед хоёр утас хоёулаа **Settings → Game Center** дээр нэвтэрсэн байх ёстой (өөр өөр Apple ID)
5. TestFlight эсвэл App Store-оор тараавал энгийн хэрэглэгчдэд шууд ажиллана

> 💡 **TestFlight**: Xcode → Product → Archive → Distribute App → TestFlight & App Store. Байршуулсны дараа App Store Connect → TestFlight хэсгээс найзуудаа имэйлээр урьж, тэд TestFlight апп-аар татаж тоглоно — Mac шаардлагагүй, 90 хоног хүчинтэй.

Цэргийн давалгаа 17 секунд тутамд хоёр талаас гарна. Дайсан алж туршлага цуглуулбал түвшин ахиж, хүч чадал нэмэгдэнэ. Дайсны талыг **Жалал ад-Дин** хунтайж (AI) удирдана.

### Ахиц дэвшил (алт, нээлт, мастери)

Тоглолт бүр **алт** олгоно — алалт, түвшин, ялалт, аварга дайчин зэргээс. Алт нь тоглоомыг хаасан ч хадгалагдана.

- **Баатар нээх:** Тэмүжин ба Зэв эхнээсээ нээлттэй. Сүбээдэй 🪙150, Мухулай 🪙300, Боорчи 🪙500, Хасар 🪙750, харин **Чингис хаан 🪙1500** — эцсийн зорилго.
- **Мастери:** Баатраар ялалт бүрд ★ од (дээд тал нь 5). Од бүр тухайн баатрын амь ба хүчийг **+3%** нэмнэ.
- **Аварга дайчин:** 5 давалгаа тутамд асар том дайчин ирнэ — унагавал их XP, 🪙25 алт.
- **Цуврал алалт:** Богино хугацаанд олон дайсан албал "Цуврал x3, x4..." урамшуулалт XP.
- Тулааны шагнал хэцүү байдлаар үржинэ: Хялбар ×0.8, Дунд ×1.0, **Хэцүү ×1.4**.

### ⚔️ Аян дайн — Нууц товчоогоор 8 түвшин

Үндсэн цэсний **АЯН ДАЙН** товчоор Монголын нууц товчоогоор дэс дараалсан 8 түвшинт кампанит ажил тоглоно. Түвшин бүр түүхэн үйл явдал ба дайсны командлагчтай:

Түвшин бүр **өөр өөр эрхэм зорилготой** (GTA маягийн даалгавар) — зүгээр хаалга нураах биш:

| # | Түвшин | Даалгавар | Дайсан |
|---|---|---|---|
| 1 | Зугталт | 🏃 Баруун гарц уруу зугтаж хүр | Тайчууд дайчин |
| 2 | Найман шарга морь | 🐎 Тарсан 8 моримо цуглуул | Хулгайн ноён |
| 3 | Бөртэг аврах | 💚 Бөртэд хүрч, гэртээ дагуулан авчир | Тогтоа бэх |
| 4 | Анд ба дайсан | ⚔️ Жамухаг 3 удаа дийл | Жамуха |
| 5 | Хэрэйдийн уналт | ⚔️ Ван ханыг 2 удаа дийл | Ван хан |
| 6 | Найманы төгсгөл | 🏰 Таян ханы их хаалгыг нураа | Таян хан |
| 7 | Хорезмын аян | 🛡 80 секунд тэсэж, довтолгоог няц | Мухаммед шах |
| 8 | Инду мөрний тулаан | 👑 Жалал ад-Диныг эцэслэн дийл | Жалал ад-Дин |

Зорилгын төрлүүд: **зугтах** (тэмдэгт цэгт хүр), **цуглуулах** (объект түү), **аврах** (NPC-г дагуулан гэрт хүргэ), **дуель** (командлагчийг N удаа дийл), **тэсэх** (хугацаа гүйцээ), **эзлэх** (хаалга нураа). Зорилгын явц дэлгэцийн дээд талд харагдана. Зугтах/цуглуулах/аврах даалгаварт **үхэл = бүтэлгүйтэл**. Түвшинг анх удаа даван туулбал дараагийн түвшин ба **Нууц товчооны** харгалзах бүлэг нээгдэж, бонус алт өгнө.

**Түүхэн танилцуулга ба динамик үйл явдал:** Түвшин бүр эхлэхийн өмнө Нууц товчоогоор сэдэвлэсэн богино түүхэн танилцуулга (илгэн цаасны хуудас) гарна. Тулааны дунд гэнэтийн үйл явдлууд тохиолдоно — **отолт** (хажуугаас дайсан гарч ирэх), **нэмэлт хүч** (дайсны шинэ давалгаа), **хилэгнэл** (командлагч хүчирхэгжих) — улаан бүрээ, дайны бөмбөрийн дуугаар зарлагдана.

### 🗺 Байлдан дагуулалтын газрын зураг

Аяны дэлгэц нь Азийн стилизацдсан газрын зураг болов. 8 түвшин бүр газрын зураг дээрх түүхэн байршилд тэмдэглэгдэнэ — цэг дээр дарж тулаанд мордоно. Түвшин даван туулах тусам **эзэлсэн нутаг дэвсгэр тэлж** (Монголын өлгий нутгаас эхлээд Төв Ази хүртэл), байлдааны зам сунаж, цэгүүд ✓ болно. Сүүлчийн түвшинг дуусгахад **түүхэн Их Монгол Эзэнт Гүрний бүрэн хүрээ** (1206–1279, Номхон далайгаас Дунай мөрөн хүртэл — түүхэн дэх хамгийн том тив залгасан гүрэн) алтан өнгөөр бүрэн нээгдэнэ.

## 🎵 Монгол өнгө аястай аудио

Тоглоомын хөгжим, авиаг монгол ардын хөгжмийн шинжээр зохиосон:
- **Хөөмий маягийн басс дрон** — гүн D2 суурь дуу, дээд аялгуут исгэрэлттэй
- **Морин хуур** — вибратотай нумт таван аялгуут (пентатоник) ая
- **Давхилтын хэмнэл** — туурайн чимээ маягийн зөөлөн цохилт
- **Дайны бөмбөр ба эвэр бүрээ (бишгүүр)** — аян эхлэх, ялах, үйл явдлын үед
- Веб хувилбарт хөгжмийг Web Audio-гоор шууд үүсгэдэг; iOS хувилбарт синтезчилсэн WAV. 🔊 товчоор унтраана.

### 📜 Монголын нууц товчоо — түүхийн горим

Аяны түвшнүүдийг даван туулах тусам **Монголын нууц товчоо**-ноос сэдэвлэсэн 8 бүлэг түүх нээгдэнэ — Бөртэ чонын домгоос эхлээд 1206 оны их хуралдай хүртэл. Сүүлчийн бүлэг **«Есөн хөлт цагаан туг»** нь аян дайныг бүрэн дуусгахад уншигдана. Үндсэн цэсний **ТҮҮХ** товчоор орно; шинэ бүлэг нээгдэхэд улаан тэмдэг гарна.
